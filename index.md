# Obligor Glance data feed

This site publishes the data pack used by the Obligor Glance browser extension. It is refreshed automatically: screening lists daily, companies weekly.

| File | Contents |
|---|---|
| [manifest.json](manifest.json) | Versions of each data file |
| [sanctions.json](sanctions.json) | Sanctions, export-control and debarment lists (normalised for screening) |
| [countries.json](countries.json) | OECD country risk classification, World Bank governance indicators, sanctions exposure by country |
| [companies.json](companies.json) | Seed companies (Wikidata + GLEIF) for 30 African markets |
| [sectors.json](sectors.json) | Line-of-business watch-points |
